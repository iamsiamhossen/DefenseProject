# KYAU CP Chapter

KYAU CP Chapter is a programming contest management platform developed for KYAU Programming Club.

It lets organizers create and run programming contests, and lets students take part individually or in teams, submit solutions, and follow ICPC-style standings.

## Technology

- Frontend: React, TypeScript, Vite, Tailwind CSS, Monaco Editor
- Backend: ASP.NET Core Web API (.NET 10), Entity Framework Core
- Database: MySQL
- Judging: Judge0 CE

## Status

Under active development.
